# CSS Selectors – Task 3

## Project Overview
This project demonstrates the use of different CSS selectors to style HTML elements without unnecessarily using classes or IDs.

## Technologies Used
- HTML5
- CSS3

## CSS Concepts Covered

1. **Element Selector:** Used to style HTML elements such as `body` and `p`.
2. **Class Selector (`.head`):** Applies blue text color to headings.
3. **ID Selector (`#bglime`):** Applies a light green background and changes font size.
4. **Descendant Selector:** Targets `span` elements inside specific IDs.
5. **Pseudo-class Selectors:**
   - `:first-child` – Highlights the first link with a yellow background.
   - `:last-child` – Highlights the last link with a blue background.
   - `:nth-child(2)` – Changes the second ordered-list item to blue.
   - `:nth-child(3)` – Changes the third ordered-list item to red.

## Features
- Different background and text colors using CSS.
- Styling elements using class and ID selectors.
- Targeting nested elements using descendant selectors.
- Highlighting anchor tags without using classes, IDs, or inline CSS.
- Styling specific list items using pseudo-classes.

## How to Run
1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same directory.
3. Open `index.html` in any web browser.

Learned how to apply CSS selectors, descendant selectors, and structural pseudo-classes to style HTML elements efficiently.
